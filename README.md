## About me

I am a developer trained at **42 Paris**, with a strong interest in low-level programming, Linux systems, computer networks and infrastructure engineering.

I enjoy building projects that help me understand how systems work beneath the application layer: network protocols, raw sockets, packet parsing, cryptographic algorithms, containers and distributed architectures.

My previous experience in the **French Army**, hospitality management and audiovisual production taught me discipline, adaptability, teamwork and responsibility.

I am currently looking for opportunities in:

* DevOps and Cloud Engineering
* Systems and Network Administration
* Cybersecurity and Network Security
* Backend and Infrastructure Development

📍 Paris area, France
